# Accessibility & Usability Standards (WCAG 2.1 AA)

- **Color Contrast**: All golden accents maintain minimum 4.5:1 contrast against dark background.
- **Keyboard Navigation**: Modals trap focus and allow Escape key dismissal.
- **Aria Attributes**: Form inputs utilize aria-labels and descriptive helper texts.
- **Responsive Touch Targets**: Buttons maintain minimum 44x44px touch targets on mobile.
- **Semantic HTML**: Proper heading hierarchy (H1 -> H2 -> H3) on all routes.
