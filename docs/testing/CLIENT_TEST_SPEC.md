# Client Unit Test Specifications

Run tests with:
```bash
npm test
```

## Suites Covered
1. `priceHelper`: Cents to dollar formatting ($50.00, $125.50)
2. `dateHelper`: Past date rejection and future date validation
3. `receiptHelper`: Printable invoice data integrity
4. `validationHelper`: Regex validation for guest email and phone
5. `authGuard`: Client role access protection matrix
