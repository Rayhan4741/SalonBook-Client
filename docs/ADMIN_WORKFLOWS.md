# Admin Dashboard Operation Workflows

## 1. Service Management
- Create treatments with image upload, title, description, duration, and price in cents.
- Edit treatments dynamically.
- Soft-toggle active/inactive state to prevent breaking existing bookings.

## 2. Appointment Review
- View all bookings across clients.
- Confirm pending reservations.
- Cancel bookings with automated notification.

## 3. Customer Moderation
- Search guests by name or email.
- Block abusive guests to restrict booking privileges.
- Unblock guests upon review.
