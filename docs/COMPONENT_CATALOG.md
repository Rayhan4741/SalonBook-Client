# SalonBook Frontend Component Catalog

## Core Components
- **Navbar**: Responsive glassmorphism navigation with role-based dashboard links.
- **Footer**: Luxury brand aesthetic with hours, address, and social links.
- **BookingModal**: Date and time slot picker with conflict validation.
- **ImageUpload**: ImgBB integrated file uploader with real-time preview.
- **StatusBadge**: Accessible status pills for appointments and services.
- **SkeletonLoader**: Shimmer skeleton for asynchronous data states.
- **ConfirmModal**: Accessible dialog for destructive actions.
- **Breadcrumb**: Nested path tracker.
